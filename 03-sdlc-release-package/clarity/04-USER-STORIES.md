# User Stories

## Borrower
As a borrower, I want to see clear status and next steps so I do not have to call support for basic updates.

Scenario: The borrower lands in Clarity, sees a readable summary, and understands what is happening without digging through internal terms.

## Servicing Agent
As a servicing agent, I want to add notes and see issue context so I can move faster and avoid repeated triage.

Scenario: An agent reviews a case, adds a note, and routes the issue without leaving the flow.

## Stakeholder / Leadership
As a stakeholder, I want to see the operating picture so I can understand friction, volume, and launch health.

Scenario: Leadership reviews trends and sees where Clarity is reducing bottlenecks and where support pressure remains.

## Support / Floor Team
As floor support, I want tickets categorized correctly so I can respond quickly and send the issue to the right owner.

Scenario: A launch ticket arrives, the chatbot suggests a category, and the human confirms the route.

## Product / Delivery
As product delivery, I want a simple release package so I can manage the mock without overbuilding it.

Scenario: The team uses the package as the shared source of truth across all three locations.
