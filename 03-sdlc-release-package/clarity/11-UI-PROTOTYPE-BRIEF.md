# UI Prototype Brief

## Purpose

This brief is the bridge from requirements to the v0 frontend prototype.

## Required Screens

- Borrower landing view
- Loan or case detail view
- Note entry or note history view
- Support triage view
- Leadership summary view
- Internal chatbot routing view

## Required Components

- Status summary card
- Read-only detail panel
- Note composer
- Routing selector
- Support queue indicator
- Severity or priority label

## Required States

- Default
- Loading
- Empty
- No data
- Error
- Routed
- Escalated

## Route Rules

- No dead pages
- Every screen should lead somewhere useful
- Every action should have a visible next step

## v0 Prompt Notes

- Use the design tokens already captured in `01-design-system-tokens/clarity.tokens.css`
- Keep the visual language close to the Nymbus palette
- Use mock data only
- Match the page tree in `02-mvp-page-tree/clarity.mvp.page-tree.md`
