# SDLC Package

This workspace folder is the source draft for the reusable `/sdlc` skill and the Clarity by Nymbus release package.

## Shape

- `skill/SKILL.md` - reusable skill instruction set
- `clarity/` - project-specific SDLC package for Clarity by Nymbus
- `.kiro/specs/clarity-by-nymbus/` - Kiro-ready mirror of the same Clarity spec set

## Rule

Keep the skill generic. Keep the Clarity package specific. Keep both lean.
