# SDLC Package

This folder is the source draft for the reusable `/sdlc` skill and the Clarity by Nymbus release package.

## Snapshot

| Artifact | Why it exists |
|---|---|
| `skill/SKILL.md` | Reusable SDLC instruction set |
| `clarity/` | Project-specific SDLC package for Clarity by Nymbus |
| `.kiro/specs/clarity-by-nymbus/` | Kiro-ready mirror of the same spec set |
| `clarity/README.md` | Plain-language approach and next steps |
| `clarity/13-AI-USAGE.md` | Audit trail for how AI was used |
| `clarity/15-V0-DESIGN-PROMPT.md` | Locked prompt for the UI image pack and v0 build |
| `clarity/11-UI-PROTOTYPE-BRIEF.md` | Bridge from requirements to the portal-style prototype |
| `clarity/12-UI-PROTOTYPE-V0-PACK.md` | Exact input pack for v0 |
| `clarity/10-CHANGE-LOG.md` | Running record of what changed and why |

## Rule

Keep the skill generic. Keep the Clarity package specific. Keep both lean.
